# CBSE PYQ Finder

**Find the questions you need without searching through entire question paper PDFs.**

CBSE PYQ Finder is a free web tool for students in Classes 10 and 12 to find previous year questions by chapter, topic, year, difficulty, and question type.

## Features

- Smart search for relevant previous year questions
- Search by chapter, topic, year, and question type
- Filters for different question formats and difficulty levels
- Worked solutions for included questions
- Free access directly in your browser
- Offline functionality

## Live Website

**https://cbsepyqfinder.netlify.app/**

## Purpose

The goal is to make CBSE exam preparation easier by helping students locate relevant practice questions quickly instead of manually searching through lengthy PDFs.

## Technology

Built using HTML, CSS, and JavaScript, with locally stored question data and smart search features.

## Subjects and Coverage

The question collection is being expanded to support more subjects and exam papers for Classes 10 and 12.
